# Repository Instructions

## Required Maintenance Files

Any change applied to this repository must update `assessment.md`.

The `assessment.md` update must reflect the current state after the change, including:

- current status
- completed work
- missing work
- risks
- validation performed
- next recommended action

Every shipped change must also be logged in `CHANGELOG.md`.

When an upgrade is implemented, move it from `future-upgrades.md` to `completed-upgrades.md` and log the same change in `CHANGELOG.md`.

Do not close a repo change with stale assessment, changelog, or upgrade tracking files.
